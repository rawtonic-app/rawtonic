# Development packaging
`npm run tauri -- build` produces DMG/app on macOS and AppImage/deb on Linux when the native SDK is installed. This Mac can qualify only Apple Silicon. No signing/notarization credentials are configured. Do not label unsigned development artifacts production-ready.

macOS (2026-10-08): `npm run package:mac` builds `Rawtonic.app` and `Rawtonic_<version>_aarch64.dmg` in `target/release/bundle/`. It sets `CI=true`, which makes Tauri's DMG script skip the Finder window styling (that AppleScript needs Automation permission for Finder and fails without it, which made a plain `tauri build` stop at the DMG). The bundle is signed ad hoc as a whole (`signingIdentity: "-"` in `src-tauri/tauri.macos.conf.json`, hardened runtime): `codesign --verify --deep --strict` passes and the app starts, renders and exports with it; before, only the binary carried the linker's ad-hoc signature and the bundle failed verification ("code has no resources"). Gatekeeper still refuses it on other Macs until it is signed with a Developer ID and notarized — that needs the owner's Apple certificate. The hardened runtime's library validation refused the bundled ONNX Runtime (Microsoft's build, signed separately; an ad-hoc signature never satisfies it), so every AI tool failed in bundled builds between 2026-10-08 (signing) and the same day's fix: `src-tauri/Entitlements.plist` grants `com.apple.security.cs.disable-library-validation`, which also works for a later Developer ID build.

Flatpak and AUR files are explicit skeletons. Flatpak needs offline vendoring and resource installation; AUR needs final resource layout and a public source URL. CI (`.github/workflows/ci.yml`) runs on Linux only, after merges into main. Intel macOS and Linux have not been run locally.

The inherited tethering feature remains source-only and unsupported until libgphoto2 moves to an isolated sidecar. The UI hides it in the default build. A `_tethering` distribution is a release blocker, not a renamed default build.

Optional local AI runtime: build with `RAWTONIC_BUNDLE_ONNX=1`; the inherited downloader verifies a pinned SHA-256. Models download only on request. Core builds do not fetch the runtime. On-demand runtime installation UI remains outstanding.
