# ADR 0002 — Evidence gates and upstream reuse
Status: accepted.
A complete LR/C1 replacement and target-hardware performance certification require camera fixtures, hardware and iterative comparison. Build working increments and record every incomplete requirement in the maintainers' parity-gap list. Imported code is labeled inherited until tested here; upstream presence is not parity or benchmark evidence.
No source from unlicensed reference-darkroom is copied. GPL references supply ideas only. Preserve provenance of imported RapidRAW code and third-party data. Original Re-touch additions are AGPL-3.0-or-later; upstream terms continue to apply.
The user's no-questions instruction overrides design-skill interviews. The explicit Capture One-like dark desktop layout overrides random style direction; retain the mature editor and introduce a session workspace.
