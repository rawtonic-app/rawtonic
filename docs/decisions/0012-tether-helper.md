# ADR 0012 — Tethering in a helper process
Status: accepted (2026-10-18). Hardware qualification per body pending (G46/G48).

**Context.** The inherited tethering (RapidRAW) called libgphoto2 inside the app, behind a build feature that was never shipped: a crash in a camera driver or a USB transfer that hangs would take the app (and any unsaved state) with it, the capture was saved outside the catalog and the file on the camera was deleted afterwards. libgphoto2 is LGPL-2.1-or-later.

**Decision.** The camera library runs only in a separate program, `rawtonic-tether` (crate `crates/tether`), which the app starts on demand and talks to over its stdin/stdout (length-prefixed JSON frames and camera JPEG frames for live view; a protocol number is checked at start). One helper thread owns the camera and polls its events between requests, so photos fired on the body arrive like the ones the app asks for. Downloads are published crash-safely into the session's `.tether/incoming/<slot>/` (temporary file, fsync, size check against the camera's report, no-clobber publication); the app ingests them through the hot folder's verified ingest with the next-capture settings, after writing what the photo is given next to it, so a crash at any point leaves either a quarantined partial download (never ingested) or a complete one that is ingested exactly once. Nothing on the camera is deleted. Which camera operation is used (trigger and wait for the file, or the blocking capture) follows libgphoto2's abilities and result codes, never a list of bodies; a shot that does not arrive is reported, never fired again.

libgphoto2, libusb and libltdl are linked dynamically into the helper alone and shipped as separate libraries, built from pinned upstream sources with only the PTP camera driver and the USB port driver (`scripts/tether/build_libgphoto2.sh`; no network port driver). The helper builds without camera support (`gphoto2` feature off) everywhere else, so CI and contributors need no libgphoto2; the scripted mock camera (`--mock`) drives the tests and the UI without a camera.

**Consequences.** A crash or hang ends only the helper; the next command starts a new one and the transfer folder is recovered. Requests cost one pipe round trip plus up to one event poll (20 ms). The bundles carry four LGPL libraries and two driver modules, and every release must offer their sources from the same place (THIRD_PARTY_NOTICES). A direct protocol path for bodies where libgphoto2 is measured below Capture One (G48) would be another backend behind the same helper protocol.
